# Video Highlight Annotator · 视频高光打标工具

一个用于**人工标注视频高光 + 智能裁剪框**的桌面工具（PySide6 + OpenCV）。

- 左上角显示**视频编号**；
- 左侧为**原视频**，可在其上拖动**裁剪框**（长宽比严格锁定官方比例）；
- 右侧为**高光预览**（裁剪后成片）；
- 下方为**可拖动时间轴**，按钮在时间轴上方；
- 打标完点 **✓** 自动保存并跳到下一个视频，直到全部完成。

## 功能特性

- 逐帧精确导航：时间轴拖动、空格播放/暂停、`←/→` 前后一帧。
- 高光打标：起点点一次、终点再点一次，两标记之间即一段高光，支持多段、撤销、点选。
- 裁剪框**比例锁定**：拖动移动、拖四角缩放，长宽比始终按官方比例。
- 裁剪框**关键帧**：在两个时间点设定框位置，中间按**线性插值**自动平滑移动（剪辑软件式打关键帧）。
- 右图**实时预览**裁剪成片。
- 一键保存：输出官方格式 `json` + 汇总 `jsonl` + **打标对比视频**，并自动跳到下一个未标注视频（断点续标）。
- 支持**预填已有结果**（可选），在其基础上人工修改。

## 安装

建议使用独立虚拟环境：

```bash
# Windows
python -m venv venv
venv\Scripts\python -m pip install -r requirements.txt

# macOS / Linux
python3 -m venv venv
venv/bin/python -m pip install -r requirements.txt
```

依赖：`PySide6` `opencv-python` `numpy` `Pillow`。

> 生成对比视频优先使用系统 `ffmpeg`（需在 PATH 中）；没有 ffmpeg 时会自动退回 OpenCV 编码（mp4v，仍可播放，文件略大）。

## 运行

```bash
# Windows
venv\Scripts\python main.py

# macOS / Linux
venv/bin/python main.py
```

首次运行会弹出**设置对话框**，需要填写：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| 源视频文件夹 | 待打标原始视频（`0.mp4`、`1.mp4`…，按编号排序） | 必填 |
| 官方比例文件夹 | 每个视频一个 `{编号}.jsonl`，内容 `{"targetRatioWH":[w,h]}`，**逐视频决定裁剪比例** | 必填 |
| 预填结果 jsonl | 已有打标结果，导入后在其基础上改；留空则从零开始 | 可选 |
| 输出文件夹 | 保存 json + 对比视频 + 汇总 jsonl | 必填 |

设置保存到 `config.json`，下次启动自动加载；主窗口点 **“设置…”** 可重新修改。

## 使用说明

### 基本导航
- 时间轴：鼠标点击 / 拖动到任意帧。
- 空格：播放 / 暂停；`←` / `→`：前一帧 / 后一帧。
- 上一个 / 下一个：切换视频（不保存）。

### 标记高光（一段 = 两个相邻标记之间）
1. 把播放头拖到高光**起点**，点 **“标记高光(起点)”**。
2. 拖到高光**终点**，再点一次（按钮会变成“标记终点”）。
3. 一段高光即生成，可重复标记**多段**高光。
4. **“撤销标记”**：先撤销未闭合的起点；否则删除最后一段。

### 裁剪框（关键帧 + 线性插值）
- 播放头落在高光段内时，左图显示裁剪框。
- **拖动框内** = 移动；**拖动四角** = 缩放（比例锁定）；松手即把该帧记为关键帧。
- **“添加关键帧”**：在当前位置记一个关键帧（保持当前框）。
- **“删除关键帧”**：删除当前位置最近的关键帧（每段至少保留一个）。
- 两个关键帧之间，裁剪框位置/宽度按**线性插值**自动平滑移动；首关键帧之前、末关键帧之后保持不动。

### 保存
- 点 **“✓ 保存并下一个”**：
  1. 保存 `{编号}.json`（官方格式）；
  2. 追加到 `annotations.jsonl`（汇总，可直接提交）；
  3. 生成 `{编号}.mp4` 对比视频（左=原片+裁剪框，右=高光成片，下=时间轴）；
  4. 自动跳到下一个视频。
- 全部完成后提示退出；中途可随时关闭，重开会自动跳到**第一个还没有 json 的视频**续标。

## 输出格式

每个视频的 json（及汇总 jsonl 中的一行）：

```json
{
  "video_id": "0",
  "targetRatioWH": [16, 9],
  "predictions": [
    {"frame": 90, "bboxes": [0, 393, 720]},
    {"frame": 91, "bboxes": [0, 392, 720]}
  ]
}
```

- `frame`：帧号（0 起始）。
- `bboxes`：`[x, y, w]` —— 裁剪框**左上角坐标** `(x, y)` 和**宽度** `w`；高度由比例自动计算 `h = w * rh / rw`。

输出文件夹结构：

```
输出文件夹/
  annotations.jsonl    # 汇总（所有已保存视频，一行一个）
  0.json                # 视频 0 的打标结果
  0.mp4                 # 视频 0 的对比视频
  1.json
  1.mp4
  ...
```

## 常见问题

- **裁剪框比例**：来自“官方比例文件夹”里的 `{编号}.jsonl`，不是固定 16:9。找不到该视频的比例时，回退到预填文件里的比例，再回退到 16:9。
- **视频打不开 / 帧数不对**：确认源视频文件夹里是 `{数字}.mp4` 命名；帧定位依赖 OpenCV 顺序解码 + 跳转，个别编码可能有 ±1 帧误差，不影响导出（导出按界面显示的帧号自洽计算）。
- **没有 ffmpeg**：对比视频仍会生成（OpenCV mp4v 编码），建议装 ffmpeg 并加入 PATH 以获得更好的兼容性。
